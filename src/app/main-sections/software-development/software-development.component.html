Introduction

Welcome to the Development Projects section, where creativity meets experimentation. Here, you’ll find a collection of small code repositories and demos that showcase a variety of programming techniques, concepts, and paradigms. From game prototypes and framework explorations to interesting ideas like multithreading or design patterns, this section is all about diving into the possibilities of code.

Each project is designed not only to highlight technical skills but also to inspire curiosity and innovation. Whether you're looking for practical examples, unique approaches, or just some programming inspiration, this is the place to start exploring.


How it works?

  1. Navigate through the different projects and with the cursor you can see what description it has and also you can see wich languages it have.
  2. Click on the project you want to see.
  3. The Nohadon Files API will connect with the github API
  4. Once all is connected the API will parse all information and it will be loaded in the page.
  5. Explore as you want!

Warning: There are some devices like smartphones where the code is not displayed correctly. For a better experience use a tablet or other devices with a large screen.
